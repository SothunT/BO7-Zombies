# BO7 Zombies Field Guide

A Black Ops 7 Zombies guide covering all six maps. Each map has these tabs:

- **Wonder Weapon:** how to build it.
- **Main Quest:** the full quest with progress checkboxes and a Guide order / Speed route toggle.
- **Side Eggs:** each card shows the reward first, then the steps.
- **Relics:** how to unlock each one, with its curse and trial.
- **Intel:** every audio log, document and artifact, with checkboxes.
- **Map:** an interactive map where you can filter pins by category.
- **Super EE:** the toy quest for this map.
- **Codes:** cipher and puzzle tools.

A separate Super Easter Egg finale page covers the boss rush.

## What's in this folder

| File | What it is |
| --- | --- |
| `index.html` | The page itself (layout and styles). |
| `js/app.js` | Everything you click: tabs, the route toggle, the map viewer, photo toggles, and the code tools. |
| `js/common.js` | Shared image-link helpers and map pin categories. |
| `js/maps/*.js` | One file per map, holding all the guide content. Edit these to fix or add info. |
| `js/maps/extra-photos.js` | Extra screenshots from other guide sites, attached to steps, side eggs, relics and toy steps. |
| `Images/` | Screenshots and map overviews. Empty until you run the downloader. |

## Using it

- **Navigating:** tap a map along the top, then a tab.
- **Photos:** tap any photo name to expand the screenshot, and tap the image to shrink it back. **Show all** opens every photo for a step.
- **Map tab:** turn categories on or off (or use **Select all** / **Select none**), search pins, and pinch, scroll or drag to zoom and pan the overview image. **Full screen** works on phones too. Pins are grouped by area, because exact coordinates aren't published.
- **Saved progress:** checkboxes (quest steps, side eggs, relics, intel), your route choice and notes you type are saved in your browser on that device.
- **Direct links:** link straight to a map and tab, for example `#toten/intel`, `#kowa/map` or `#rex/side`. Use `#boss` for the Super EE finale.
